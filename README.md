# Gregario Leads — Pipeline de prospección B2B Horeca MX

## Contexto

Este repositorio contiene un pipeline de generación de leads B2B enfocado en el canal Horeca (hoteles, restaurantes y cafeterías) en México. Automatiza la identificación, enriquecimiento y calificación de prospectos a partir de un ICP definido por el cliente, produciendo listas de contacto accionables para el equipo comercial.

## Protección de datos

Este proyecto maneja datos personales de terceros (nombres y teléfonos de contactos B2B en México) y está sujeto a la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP).

**Los datos de contacto NO se versionan** por cumplimiento con la LFPDPPP y por acuerdo explícito con el cliente. Los archivos ubicados en `inputs/`, `outputs/` y `data/` son estrictamente locales y **no deben subirse nunca** al repositorio remoto. El `.gitignore` del proyecto bloquea estos directorios; cualquier excepción requiere aprobación formal del cliente.
